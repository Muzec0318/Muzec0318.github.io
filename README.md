## About me

I work as a penetration tester and red teamer. Outside of client work I play CTFs and root machines on HackTheBox and Proving Grounds, and I publish a full writeup for every one on my blog. The goal is simple: show the real thinking behind each step, not just the final flag.

## What I do

- **Network and Active Directory pentesting:** enumeration, Kerberoasting, BloodHound attack paths, lateral movement and pivoting
- **Web application testing:** SQL injection, LFI, SSTI, code review for authentication bypasses
- **Red teaming:** payload development and antivirus evasion, including PowerShell and AMSI bypass techniques
- **Writing and teaching:** step-by-step writeups that explain why an attack works, not only what to type
